## C. Runtime 凭据注入

保存档案时，Electron Main 通过 `safeStorage` 解密凭据并放入 Runtime 子进程环境，配置文件只保存对应变量名。本轮用 Windows 进程环境块读取器检查运行中的内嵌 Python Host。删除最后一个 Provider 后，没有 `AGENTDU_DESKTOP_PROFILE_*_KEY`、`AGENTDU_API_KEY` 或 `OPENAI_API_KEY`，也没有合成密钥。隔离 `userData` 下的 Runtime 日志与文本文件扫描均未发现合成密钥明文。

本轮 Electron Main 崩溃任务通过仅监听 `127.0.0.1` 的本机合成 OpenAI-compatible 流式端点运行。端点日志只保存模型名、路由、流式标志、是否收到 Authorization 和时间戳，不保存授权头或提示正文。该请求验证桌面到本机测试服务的实际 HTTP 路径，不构成真实 Provider 或真实模型能力验证。
